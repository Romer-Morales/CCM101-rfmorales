# Laboratory Activity 1 – Welcome to the Cloud

## Mission Overview
This is the first laboratory activity for CCM101. The goal is to learn how to work inside a Linux environment using KillerCoda, gather system information, organize files, and create a professional GitHub portfolio.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
- Launched Ubuntu playground on KillerCoda
- Created a new user account (`rfmorales`) with sudo privileges
- Gathered system information (distribution, kernel, CPU, memory, disk)
- Created folder structure (Documents, Notes, Reports, Screenshots)
- Created personal Markdown files
- Created GitHub portfolio repository `CCM101-rfmorales`

## Linux Commands Used
- `sudo adduser`
- `sudo usermod -aG sudo`
- `su -`
- `whoami`, `pwd`, `hostname`
- `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
- `mkdir`, `ls`, `cd`, `nano`, `cat`

## Skills Learned
- Basic Linux navigation and user management
- Gathering system information
- Creating and editing Markdown files
- Setting up a professional GitHub repository
- Proper documentation practices for cloud engineers
