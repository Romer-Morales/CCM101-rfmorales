# Laboratory Activity 2 – Build the Cloud Infrastructure Blueprint

## Mission Overview
This laboratory activity focuses on understanding the basic components of cloud infrastructure. I investigated a Linux server in KillerCoda, identified compute, storage, networking, and operating system resources, compared the major cloud providers, and designed a simple cloud architecture.

## Objectives
- Explain the major components of cloud infrastructure
- Investigate hardware and software resources in a Linux environment
- Differentiate compute, storage, networking, and identity resources
- Create professional technical documentation using Markdown
- Continue building a structured GitHub Cloud Computing Portfolio

## Cloud Infrastructure Components
- **Compute** – Provides CPU and memory to run applications
- **Storage** – Stores data and files
- **Networking** – Allows communication between resources and users
- **Operating System** – Manages the hardware and software
- **Identity and Access Management** – Controls who can access resources
