# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world’s leading cloud computing platform. It was launched by Amazon in 2006 and offers a wide range of cloud services.

## Global Infrastructure
AWS has the largest global infrastructure with many Regions and Availability Zones around the world.

## Cloud Management Console
AWS Management Console (https://console.aws.amazon.com)

## Four Core Services
1. **Amazon EC2** – Virtual servers (Compute)
2. **Amazon S3** – Object storage
3. **Amazon VPC** – Virtual networking
4. **AWS IAM** – Identity and Access Management

## Three Advantages
1. Broadest range of services
2. Highly reliable and scalable
3. Largest global infrastructure

## Typical Enterprise Use Cases
- Hosting websites and applications
- Big data and analytics
- Backup and disaster recovery
- Machine learning projects
