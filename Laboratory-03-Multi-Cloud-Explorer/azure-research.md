# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft’s cloud computing platform. It is especially strong for companies that already use Microsoft products.

## Global Infrastructure
Azure has a large number of regions worldwide and continues to expand.

## Cloud Management Console
Azure Portal (https://azure.com)

## Four Core Services
1. **Virtual Machines** – Compute
2. **Blob Storage** – Object storage
3. **Virtual Network (VNet)** – Networking
4. **Microsoft Entra ID** (Azure Active Directory) – Identity

## Three Advantages
1. Excellent integration with Microsoft products
2. Strong hybrid cloud capabilities
3. Good for enterprise and government organizations

## Typical Enterprise Use Cases
- Migrating Windows servers to the cloud
- Microsoft 365 and Active Directory integration
- Enterprise applications
- Hybrid cloud environments
