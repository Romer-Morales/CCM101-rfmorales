## Guide Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers the broadest range of services. It has been in the market the longest and provides the most complete set of cloud services.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure best integrates with Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform is strongest in Artificial Intelligence, Machine Learning, and Kubernetes (Google Kubernetes Engine).
