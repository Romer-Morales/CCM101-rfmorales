# Laboratory Activity 5 – The Cloud Data Engineer

## Mission Overview
This laboratory activity focuses on Object Storage. I researched the differences between Block, File, and Object Storage, deployed a MinIO object storage server using Docker, created a bucket named client-photos, and uploaded a test file.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy an S3-compatible Object Storage server (MinIO) using Docker
- Access a cloud service via a web interface using port forwarding
- Create a storage bucket and upload objects
- Document cloud storage operations using Markdown

## Tools Used
- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Markdown

## Skills Learned
- Understanding different types of cloud storage
- Deploying MinIO with Docker
- Accessing services using port forwarding
- Creating buckets and uploading files
- Documenting technical procedures
