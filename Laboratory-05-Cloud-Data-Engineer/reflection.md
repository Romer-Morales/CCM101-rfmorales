# Reflection – Laboratory Activity 5

1. Why is object storage better suited for storing millions of photos compared to a traditional block storage hard drive?
Object storage is designed to handle massive amounts of unstructured data such as photos and videos. It can easily scale to millions of files without the limitations of a single hard drive...

2. How did using Docker make it easier to deploy the MinIO storage server?
Using Docker allowed me to deploy the entire MinIO server with just one command. I did not need to install MinIO manually or configure many settings...

3. What is a "bucket" in the context of cloud storage?
A bucket is like a folder or container used to organize and store objects (files) in object storage systems such as MinIO or Amazon S3...

4. How do you think large enterprise companies ensure their object storage data is not lost if the physical server crashes?
Large companies use replication and redundancy. Data is automatically copied across multiple servers and even different geographic locations...

5. How is your confidence in navigating the Linux command line growing?
My confidence continues to improve. I can now run Docker commands, check running containers, and deploy services more comfortably...
