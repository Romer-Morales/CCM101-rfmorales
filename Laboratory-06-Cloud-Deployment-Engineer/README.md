# Laboratory Activity 6 – The Cloud Deployment Engineer

## Mission Overview
This laboratory activity introduces Docker Compose and multi-tier architecture. I deployed a complete Nextcloud + MariaDB private cloud storage system using a single `docker-compose.yml` file (Infrastructure as Code).

## Objectives
- Explain multi-tier application architecture
- Understand the structure of a docker-compose.yml file
- Use nano to create configuration files
- Deploy a multi-container application using Docker Compose
- Document Infrastructure as Code (IaC) principles

## Tools Used
- KillerCoda Ubuntu Playground
- Docker & Docker Compose
- nano text editor
- Nextcloud + MariaDB
- GitHub
- Markdown

## Skills Learned
- Writing a docker-compose.yml file
- Deploying multi-container applications
- Understanding Web Tier and Database Tier
- Using Infrastructure as Code (IaC)
- Accessing services through port forwarding
