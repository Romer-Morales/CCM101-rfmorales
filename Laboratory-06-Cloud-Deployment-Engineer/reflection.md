**1. What is the advantage of using Docker Compose instead of running multiple docker run commands?**
For me docker Compose allows me to define the entire application in one file and start everything with a single command. This reduces errors and makes the deployment much easier and more professional.

**2. Why is it important to separate the web application and the database into different containers?**
From my Research separating them follows the multi-tier architecture principle. It makes the system more flexible, easier to scale, and easier to maintain. If one part has a problem, the other can still function .

**3. What does “Infrastructure as Code” mean based on this laboratory?**
