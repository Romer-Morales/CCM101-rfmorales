# Laboratory Activity 7 – The Cloud Operations Engineer

## Mission Overview
This laboratory focuses on Observability and Monitoring. I established a system baseline for the Linux host, deployed an Nginx container, generated test traffic, and collected performance metrics and logs to verify the health of the application.

## Objectives
- Monitor host CPU, Memory, and Disk using Linux tools
- Deploy a web container and track its performance
- Generate web traffic and analyze access logs
- Document performance data using Markdown

## Tools Used
- KillerCoda Ubuntu Playground
- Docker
- Linux commands (`free`, `df`, `top`, `docker stats`, `docker logs`)
- GitHub
- Markdown

## Skills Learned
- Establishing a system performance baseline
- Using `docker stats` for real-time container monitoring
- Reading application logs
- Translating raw metrics into a technical report
