# Container Observability

## Deployed Application
- Container Name: `webserver`
- Image: `nginx`
- Port Mapping: `8080:80`

## Commands Used for Monitoring

| Command              | Purpose                                      |
|----------------------|----------------------------------------------|
| `docker ps`          | List running containers                      |
| `docker stats`       | Show real-time CPU, Memory, and Network usage|
| `docker logs webserver` | View application access logs              |
| `curl http://localhost:8080` | Generate test traffic                   |
