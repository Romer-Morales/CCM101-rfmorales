# Reflection – Laboratory Activity 7

# 1. Why is it important to check the host server's resources even if your containers are running perfectly?  
It is important to check the host server’s resources because containers still depend on the underlying host for CPU, memory, and disk space. Even if the containers appear to be running fine, the host may be running out of memory or disk space, which can eventually cause the containers to fail or become slow.

# 2. If a user complains that they cannot log into a web application, how would the docker logs command help you solve the problem?  
The `docker logs` command would help by showing the application’s access and error logs. From the logs, I can see if there are any error messages, failed login attempts, or problems with the application that explain why the user cannot log in.

# 3. What is the difference between monitoring logs (Checkpoint 4) and monitoring metrics (Checkpoint 5)?  
Monitoring logs shows the detailed events and messages generated by the application (what happened), while monitoring metrics shows numerical performance data such as CPU usage, memory usage, and network traffic (how the system is performing). Logs help with troubleshooting specific problems, while metrics help understand overall health and performance.

# 4. How do you think large enterprise companies monitor thousands of containers at the same time?  
Large enterprise companies use specialized monitoring tools such as Prometheus and Grafana. Prometheus collects metrics from many containers, and Grafana displays the data in dashboards so engineers can easily see the health of thousands of containers at the same time.

# 5. How has your ability to troubleshoot Linux environments improved?  
My ability to troubleshoot Linux environments has improved significantly. I can now check system resources using commands like `free`, `df`, and `top`, monitor containers with `docker stats`, and investigate problems using `docker logs`. These skills help me find and understand issues more quickly and systematically.
