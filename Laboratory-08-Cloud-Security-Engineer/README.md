# Laboratory Activity 8 – The Cloud Security Engineer

## Mission Overview
This laboratory focuses on basic cloud security using a host-based firewall. I deployed a web application, audited open ports, and configured UFW with a Default Deny policy while allowing only necessary traffic (SSH and HTTP).

## Objectives
- Understand Attack Surface and Principle of Least Privilege
- Perform a basic security audit of open ports
- Configure UFW with a Default Deny policy
- Allow only required ports (SSH and HTTP)
- Document firewall rules and security best practices

## Tools Used
- KillerCoda Ubuntu Playground
- Docker (Nginx)
- Uncomplicated Firewall (UFW)
- `ss` / `netstat`
- GitHub
- Markdown

## Skills Learned
- Reducing the attack surface
- Applying the Principle of Least Privilege
- Configuring a host-based firewall
- Allowing only necessary network traffic
