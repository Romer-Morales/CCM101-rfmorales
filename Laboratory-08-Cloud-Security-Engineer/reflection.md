# Reflection – Laboratory Activity 8

## 1. What is the Attack Surface and why is it important to reduce it?  
As for me The attack Surface includes all the possible entry points that an attacker can use to access a system. Reducing it is important because fewer open ports and services mean fewer opportunities for unauthorized access or attacks.

## 2. How does the Principle of Least Privilege apply to firewall configuration?  
For me the Principle of Least Privilege means allowing only the minimum access that is needed. In the firewall, this is applied by using a Default Deny policy and only opening the ports that are required (SSH and HTTP).

## 3. Why is it dangerous to leave unnecessary ports open on a cloud server?  
I think leaving unnecessary ports open increases the risk of automated attacks such as brute-force attempts. Attackers constantly scan the internet for open ports, so any unused open port becomes a potential vulnerability.

## 4. What did you learn about using UFW in this laboratory?  
I learned how to set default policies, allow specific ports, enable the firewall, and check its status. UFW makes it simple to apply basic but effective security rules on a Linux server.

## 5. How has your understanding of cloud security improved after this mission?  
I now understand that security is not only about installing tools but also about continuous configuration and monitoring. Applying a Default Deny policy and limiting open ports is a practical way to protect cloud servers.
