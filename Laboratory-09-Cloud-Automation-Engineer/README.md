## Mission Overview
This laboratory introduces Bash scripting and task automation using Cron. I created a simple backup script, made it executable, tested it, and scheduled it to run automatically.

## Objectives
- Understand basic Bash script syntax
- Write and save scripts using nano
- Modify file permissions using chmod
- Schedule tasks using crontab
- Document automation processes

## Tools Used
- KillerCoda Ubuntu Playground
- nano text editor
- Bash scripting
- chmod
- crontab
- GitHub
- Markdown

## Skills Learned
- Writing simple Bash scripts
- Making scripts executable
- Scheduling automated tasks with Cron
- Understanding the importance of automation in cloud environments
