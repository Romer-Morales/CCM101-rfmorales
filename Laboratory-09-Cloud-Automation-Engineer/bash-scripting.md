# Bash Scripting and Automation Concepts

## What is a Bash Script?
A Bash script is a plain text file that contains a series of Linux commands. Instead of typing the commands one by one, the script runs them automatically in order.

## Why Automate?
If you have to do a task more than twice, you should automate it. Automation reduces human error and saves time, especially when managing many servers.

## What is Cron?
Cron is a Linux scheduler that allows you to run scripts or commands automatically at specific times (for example, every day at midnight).

## Important Commands
| Command              | Purpose                                      |
|----------------------|----------------------------------------------|
| `nano filename.sh`   | Create or edit a script                      |
| `chmod +x filename.sh` | Make the script executable                 |
| `./filename.sh`      | Run the script                               |
| `crontab -e`         | Edit the Cron schedule                       |
| `crontab -l`         | List current Cron jobs                       |
