# Reflection – Laboratory Activity 9

## 1. Why is automation important in cloud environments?
Automation is important in cloud environments because manual work becomes too slow and highly prone to human error when managing many servers. In large-scale systems, administrators cannot repeatedly type the same commands every day. Automating repetitive tasks saves a significant amount of time, reduces mistakes, and allows the team to focus on more important work. This is why the common rule in cloud computing is: if you have to do a task more than twice, you should automate it.

## 2. What is the purpose of the `chmod +x` command?
The `chmod +x` command gives execute permission to a file. Without this permission, a Bash script cannot be run as a program. After creating the script, this command is necessary so that the system will allow it to execute.

## 3. How does Cron help system administrators?
Cron helps system administrators by allowing them to schedule scripts and commands to run automatically at specific times. Once a Cron job is configured, the administrator no longer needs to manually run the task. This is very useful for backups, monitoring, and other routine operations that need to happen regularly.

## 4. What did you learn from creating and scheduling a Bash script?
I learned how to write a simple Bash script using nano, make it executable with `chmod +x`, test it, and schedule it using crontab. I also learned the basic structure of a Cron job. These skills are fundamental for cloud automation and will be useful in real production environments.
