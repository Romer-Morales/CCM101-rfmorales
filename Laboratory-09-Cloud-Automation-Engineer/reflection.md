# Reflection – Laboratory Activity 9

1. Why is automation important in cloud environments?  
Automation is important because manual work becomes too slow and error-prone when managing many servers. Automating repetitive tasks saves time and reduces human mistakes.

2. What is the purpose of the `chmod +x` command?  
The `chmod +x` command gives execute permission to a file so that it can be run as a program or script.

3. How does Cron help system administrators?  
Cron allows administrators to schedule scripts and commands to run automatically at specific times without manual intervention.

4. What did you learn from creating and scheduling a Bash script?  
I learned how to write a simple script, make it executable, test it, and schedule it using crontab. This is a basic but powerful skill for cloud automation.

5. How has your GitHub portfolio improved after completing all nine laboratory activities?  
My GitHub portfolio is now complete. It shows a clear progression from basic Linux commands to Docker, multi-container deployments, monitoring, security, and finally automation. It demonstrates practical cloud computing skills.
