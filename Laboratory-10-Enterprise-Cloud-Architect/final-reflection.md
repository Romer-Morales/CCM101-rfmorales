# Final Reflection – Laboratory Activity 10

Completing Laboratory Activity 10 marks the end of my journey in CCM101 – Cloud Computing. From the first laboratory where I learned basic Linux commands to this final mission as an Enterprise Cloud Architect, I have grown significantly in both technical skills and confidence.

In this final project, I independently designed and deployed a multi-tier application using Nextcloud and MariaDB. I configured persistent volumes so that data would survive container restarts, secured the server using UFW with a Default Deny policy, and automated daily backups using a Bash script and Cron. These tasks required me to combine knowledge from all previous laboratories: Linux administration, Docker, multi-container deployments, security, monitoring, and automation.

One of the biggest challenges was troubleshooting YAML indentation errors and Docker permission issues. Through these problems, I learned the importance of careful configuration and systematic debugging. I also realized that real-world cloud infrastructure requires not only technical skills but also clear documentation and the ability to explain and defend design decisions.

My GitHub portfolio now contains ten complete laboratory activities that demonstrate a clear progression from beginner to more advanced cloud concepts. I am proud of the work I have produced and feel more prepared to take on real-world cloud computing tasks. This final mission has taught me that an architect does not simply follow instructions — they design, build, secure, automate, and take responsibility for the entire system.
